# 21-number-game-python
A simple 21 Number Game built in Python where the user plays against the computer. Players take turns choosing 1 to 3 numbers, and the player who reaches 21 loses.

# 21 Number Game in Python

A simple command-line implementation of the classic 21 Number Game using Python.

## How to Play

* The game starts at 0.
* The user and computer take turns.
* On each turn, a player can add 1, 2, or 3 numbers.
* The current number increases accordingly.
* Whoever reaches 21 loses the game.

## Features

* User input validation
* Random computer moves
* Turn-based gameplay
* Simple command-line interface

## Requirements

* Python 3.x

## Run the Game

```bash
python "21 Number game.py"
```
